# Интерактивная карта внутренней Идании

Русская локальная версия карты «Следы и наследие Тахиона». Сохранены поиск, фильтры, масштабирование, галерея скриншотов, отметки прохождения и импорт/экспорт прогресса.

## Запуск

Из этой папки выполните:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173/`.

Прогресс хранится в браузере. Кнопки «Сохранить» и «Загрузить» позволяют перенести его на другой компьютер.

## Публикация на GitHub Pages

Проект уже содержит workflow `.github/workflows/pages.yml`. После загрузки в публичный репозиторий:

1. Откройте `Settings → Pages`.
2. В разделе `Build and deployment` выберите источник `GitHub Actions`.
3. Запустите workflow `Deploy static map to GitHub Pages` или отправьте новый коммит в ветку `main`.

Адрес будет иметь вид `https://ИМЯ.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Проверка

```powershell
node scripts/smoke-test.mjs
```

Проверка подтверждает количество маркеров, тайлов и скриншотов, наличие всех файлов и полноту русской локализации пользовательских названий.

## Обновление копии исходных ресурсов

`scripts/download-source.ps1` повторно загружает актуальные файлы данных и недостающие ассеты исходной карты, сохраняя русскую страницу и локализацию. Версии файлов скрипт определяет по текущей странице источника. Для загрузки оригинального `index.html` используйте параметр `-IncludeIndex`.

## Источник

Русская версия основана на публичной карте `https://www.korbdo.co.kr/map/Edania2/index.html`.

Оригинальная карта принадлежит разработчику сайта [korbdo.co.kr](https://www.korbdo.co.kr/#tachyon). Авторство исходной карты, кода и материалов сохраняется за их создателями. Отдельная ссылка на автора игровых скриншотов сохранена внутри галереи.
